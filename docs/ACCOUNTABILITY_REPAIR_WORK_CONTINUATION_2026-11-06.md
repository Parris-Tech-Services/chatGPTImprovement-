## Root cause, without another accountability product

1. **Adoption/invocation gap:** verifier CLIs exist, but hosted chats and multiple coding-agent clients are not universally hooked into them. A PR can still be technically green if an original exclusion was never captured.
2. **Evidence boundary:** cryptographic or CI checks can prove a recorded event, not that an omitted original requirement was remembered. AgentWitness currently **fails closed** on an unsupported contract field rather than pretending to understand its semantics.
3. **Automation delivery gap:** the scheduled daily audit executed but did not persist a new rotation checkpoint. A validator that runs only when explicitly invoked cannot ensure a scheduled agent writes state.
4. **Operational dependence:** approval-safe deploy failover, protected notary, actual handset tests and third-party browser/session hooks cannot be proclaimed completed from repository documentation.
